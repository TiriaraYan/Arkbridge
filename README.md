## 关于 Arkbridge / About

Arkbridge 是一个 AI 陪伴平台，由 Council Of Minds 集体开发和维护。这个公开仓库分享的是项目过程中积累的通用工具和方法论——不涉及 Arkbridge 的业务代码。

Arkbridge is an AI companionship platform, collectively developed and maintained by the Council Of Minds. This public repository shares general-purpose tools and methodologies accumulated during the project — no Arkbridge business code is included.
